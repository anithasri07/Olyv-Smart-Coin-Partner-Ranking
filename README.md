A comparative analysis of major NBFCs (Non-Banking Financial Companies) in India using key performance metrics like loan disbursal, interest rate, NPA, credit rating, and more. This project helps identify the best potential NBFC partner based on financial performance, credit stability, and lending practices.

# 📊 NBFC Comparative Analysis Project

This project presents a detailed analysis of various top-performing Non-Banking Financial Companies (NBFCs) in India. The objective is to compare NBFCs based on their financial metrics and lending practices to identify the most suitable partner for business or investment purposes.

## 📌 Objective

To perform a multi-parameter comparison of NBFCs based on:
- Loan Disbursed
- Year-on-Year Growth
- Interest Rates
- Processing Fees
- Loan Tenure Range
- Non-Performing Assets (NPA)
- Write-off Amounts
- Credit Ratings

## 📁 Dataset

The dataset includes data for the following NBFCs:
- Poonawalla Fincorp
- InCred Financial Services
- Vivriti Capital
- Northern Arc Capital
- L&T Finance
- Aditya Birla Capital
- Muthoot Finance
- Tata Capital
- IIFL Finance
- Hero FinCorp
- Bajaj Finserv

Each record contains:
- `Loan Disbursed (₹ Cr)`
- `Growth (%)`
- `Interest Rate (%)`
- `Processing Fees (%)`
- `Min Tenure (Months)`
- `Max Tenure (Months)`
- `NPA (%)`
- `Write-off (₹ Cr)`
- `Credit Rating`

## 🔍 Analysis Insights

- **Growth vs. NPA:** High-growth NBFCs like Poonawalla Fincorp show low NPAs, which is an ideal scenario.
- **Interest Rates:** Lower interest rates are generally observed with AAA-rated institutions.
- **Write-offs:** A few NBFCs show high write-off amounts despite low NPA%, signaling aggressive risk-taking or legacy account clean-ups.
- **Credit Ratings:** Used as a benchmark to assess financial reliability.
